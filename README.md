# behavioral-drift-detection

Research on detecting behavioral drift in autonomous systems from operational records.

## Contents

- `paper/behavioral-drift-detection-survey.md` — working draft: *Behavioral Drift in Autonomous Systems: A Survey of Detection Approaches and the Case for Deterministic Detection*. Surveys eight detection approaches, proposes a detectability matrix across seven drift phenomena, and argues that the detection core must be deterministic because an LLM judge is itself a drifting system.
